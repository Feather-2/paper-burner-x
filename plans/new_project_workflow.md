# PPT 创作入口流程重构提案 (Product Perspective)

## 1. 核心痛点分析
目前的“生成配置”和“开始新创作”混合在一起，导致：
- **认知负荷高**：用户进入后面对一堆按钮，不知道哪个是自己真正需要的。
- **目标不明确**：是想写报告？还是想做 PPT？还是想改现有的 PPT？
- **路径重叠**：导入 PPTx 的功能既出现在上传区，又可能作为某种模式，逻辑不清晰。

## 2. 建议重构逻辑：基于“用户意图”
我们将入口分为三大清晰的**意图路径**：

### 路径 A：研究先行型 (Research-Driven)
**用户目标**：“我只有一些碎资料，或者一个模糊的想法，需要 AI 帮我深度挖掘并梳理成体系。”
- **选项 A1：深度分析并生成 PPT**
    - 流程：上传资料/想法 -> 深度研究 (DeepSearch) -> 生成详细报告 -> 自动生成 PPT。
- **选项 A2：仅深度研究（输出报告）**
    - 流程：上传资料/想法 -> 深度研究 (DeepSearch) -> 输出 Markdown/PDF 报告 -> 结束。

### 路径 B：结构化快速型 (Structure-Focused)
**用户目标**：“我有明确的内容要求或大纲，希望快速看到每页长什么样，并能通过对话微调。”
- **选项 B1：按需快速生成**
    - 流程：输入大纲/要求 -> 快速生成每页草图 -> 通过“简单反馈（对话）”模式即时修改内容/样式。

### 路径 C：资产继承型 (Asset-Based)
**用户目标**：“我已经有现成的 PPT 了，我只是想在现有的基础上改改，或者换个风格。”
- **选项 C1：从现有 PPT 导入**
    - 流程：上传 .pptx -> 解析为 DSL -> 进入编辑器 -> 通过 AI 或手动修改。

---

## 3. UI 布局建议

### 第一级：开始新创作 (Start New Project) - 模态框或独立视图
采用三个并排的“意图大卡片”：

1.  **[深度研究模式]**
    *   标题：AI 深度调研
    *   描述：从零开始，AI 联网搜索并分析资料，生成深度报告及 PPT。
    *   标签：适合：市场调研、竞品分析、主题演讲。

2.  **[快速对话生成]**
    *   标题：结构化速成
    *   描述：根据已有大纲或素材，通过对话快速搭建 PPT 框架。
    *   标签：适合：工作总结、培训课件、快速汇报。

3.  **[导入已有模板]**
    *   标题：导入 PPTx 修改
    *   描述：上传现有 PPT，转为可编辑格式并进行 AI 智能重塑。
    *   标签：适合：旧版翻新、内容纠错、风格迁移。
