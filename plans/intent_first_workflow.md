# PPT 创作路径预选流程 (Intent First Strategy)

## 1. 设计构想：意图在前
**逻辑**：用户进入“开始新创作”后，第一眼看到的是三个**独立的、大幅的、极具视觉表现力**的路径卡片。这作为 `Step 0` 或 `Step 1` 的入口。

### 1.1 三大路径卡片设计
1.  **AI 深度调研与生成 (DeepSearch)**
    - 视觉：雷达、网络、大脑。
    - 适用：零碎资料、复杂主题。
2.  **CodeSearch 源码文档化**
    - 视觉：代码流、架构图。
    - 适用：工程分析、技术汇报。
3.  **PPT 资产修改与重塑 (Import)**
    - 视觉：文档翻页、转换。
    - 适用：旧 PPT 优化、DSL 转换。

## 2. 界面层级拆分
- **第一层 (路径选择)**：展示上述三张大卡片，占据主视口，背景极简。
- **第二层 (对应模式的投喂区)**：
    - 点击 DeepSearch 后，滑入“素材上传+需求填写”界面。
    - 点击 CodeSearch 后，滑入“代码库关联+分析目标”界面。
    - 点击 Import 后，滑入“PPTx 拖拽区”。

---

## 3. UI 交互细节 (Visual Quality)
- **卡片动画**：Hover 时卡片放大并出现发光边缘。
- **平滑切换**：点击后，当前选中的卡片向左滑动成为侧边缩略引导，主视口滑入对应模式的配置项。
- **高度适配**：因为每一层只专注一个任务，内容量极大降低，彻底解决“放不下”的问题。
