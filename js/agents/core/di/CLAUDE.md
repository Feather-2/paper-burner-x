# di - 依赖注入\n\nIoC 容器，管理服务生命周期与解析规则（支持父子容器、默认注册、legacy 全局兼容层）。\n\n## 核心文件\n\n| 文件 | 职责 |\n|------|------|\n| `index.js` | 模块入口导出（Container / Scope / ServiceId / 默认容器工厂） |\n| `container.js` | `Container` - IoC 容器实现（scope、懒加载、父子回退、`tryGet`） |\n| `defaults.js` | 默认服务注册（`ServiceId` + 默认工厂），通过动态 `import()` 打破循环依赖 |\n| `global-container.js` | 全局容器兼容层（仅供 legacy `getGlobalX()` 访问） |\n\n## 生命周期（Scope）\n\n```javascript\nexport const SINGLETON = Symbol('singleton'); // 单例：同一容器内只创建一次\nexport const TRANSIENT = Symbol('transient'); // 瞬时：每次解析创建新实例\n```\n\n## 解析规则（父子容器）\n\n- `new Container(parent)` 支持“测试覆写 + 父容器回退”。\n- 解析顺序：先当前容器，再回退到 `parent`（若存在）。\n- 建议：生产代码显式传递 `container`；测试中用 child container 注入 mock/override。\n\n## `tryGet` 告警策略\n\n- `tryGet(id)` 未注册时返回 `undefined`（用于可选依赖）。\n- 默认在非 production 环境输出 `console.warn`。\n- production 判定顺序：\n  1. `globalThis.process?.env?.NODE_ENV === 'production'`\n  2. `import.meta.env?.MODE === 'production'`\n- 若环境探测不可用/抛错，默认按非 production 处理（保留告警）。\n\n## `defaults.js` 设计要点\n\n- `ServiceId` 统一管理系统服务标识（字符串 ID）。\n- 默认注册覆盖核心总线、容错、路由、预算、检索、运行时适配器等服务。\n- 以下模块改为“工厂内动态导入”以打破循环依赖并提升 Browser-first 兼容性：\n  - `InjectionScanner`\n  - `FileLock`\n  - `createDefaultErrorBoundary`\n  - `TokenTracker` / `TraceContext`\n  - `enhanceEventBusWithHooks`\n\n## Browser-first 兼容性\n\n- 保持 ES Modules（`import/export`），避免 `require()`、`__dirname`、`__filename`。\n- Node-only 能力应放入动态 `import()` 分支并进行环境判断，避免浏览器静态打包引入。\n- 环境探测通过 `globalThis` + `import.meta` 双通道实现，兼容 Browser / Node / Bundler。\n\n## 全局容器兼容层\n\n- `global-container.js` 提供进程级（process-wide）单例容器，服务 legacy 接口。\n- 新代码应避免依赖全局容器，优先显式依赖注入（传 `container`）。\n- 测试建议使用 child container 隔离，避免全局状态污染。\n\n## 使用示例\n\n```javascript\nimport { Container, SINGLETON, TRANSIENT, ServiceId } from 'js/agents/core/di/index.js';\n\nconst container = new Container();\n\n// 注册单例\ncontainer.register(ServiceId.LOGGER, () => console, { scope: SINGLETON });\n\n// 注册工厂（支持 async factory）\ncontainer.register(\n  ServiceId.EVENT_BUS,\n  async (c) => {\n    const logger = await c.get(ServiceId.LOGGER);\n    return { logger };\n  },\n  { scope: TRANSIENT }\n);\n\n// 解析（异步工厂需要 await）\nconst eventBus = await container.get(ServiceId.EVENT_BUS);\n```\n\n## 常用 API\n\n```javascript\ncontainer.register(id, factory, { scope: SINGLETON });\ncontainer.registerValue(id, value);\n\nconst service = await container.get(id);\nconst maybeService = container.tryGet(id);\n\n// 覆盖/重置（测试用）\ncontainer.override(id, factory);\ncontainer.reset();\n```
