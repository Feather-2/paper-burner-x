# 报告撰写

## 能力

- 生成完整报告（标题、摘要、正文、结论）
- 写单个章节
- 整合多个信息源
- 添加引用和出处

## 使用时机

- 信息收集充分，可以开始写作
- 需要输出某个主题的总结
- 用户要求生成报告

## 判断"信息充分"

不需要完成所有任务，关键是：
- 核心问题能够回答
- 有足够的证据支撑
- 主要观点已经明确

## 输出格式

Markdown 格式，包含：
- 标题和摘要
- 分章节的正文
- 引用标记 [^1] 和引用列表
