# 文档搜索

## 能力

- 关键词搜索（grep 模式）
- 语义搜索（向量相似度）
- 获取上下文片段
- 定位原文出处

## 使用时机

- 需要查找特定概念/术语
- 验证某个论点是否有依据
- 寻找支撑证据
- 了解文档中某主题的覆盖情况

## 输入

- query: 搜索查询（关键词或自然语言问题）
- sources: 可选，限定搜索范围的文档 ID 列表
- limit: 可选，返回结果数量限制

## 输出

- 匹配的文本片段
- 来源信息（文档 ID、位置）
- 相关度分数
