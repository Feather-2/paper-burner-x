# 任务管理

## 能力

- 创建新任务（text, priority, queryHints）
- 更新任务状态（open → in_progress → completed/cancelled）
- 任务分解（将大任务拆成小任务）
- 查看当前任务列表

## 使用时机

- 开始新研究时：创建初始任务规划
- 发现新问题时：添加新任务
- 完成某项工作时：标记完成
- 任务太大时：拆分成子任务

## 注意

- 任务是软指导，不是硬性要求
- 可以根据情况调整、删除、重新规划
- 任务状态会展示给用户看
